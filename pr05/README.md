# Практическая работа №5
## Алгоритмы планирования процессов

### 1. Цель работы

Изучить алгоритмы планирования процессов FCFS, SJF и Round Robin (RR), реализовать их на Python и сравнить результаты.

### 2. Описание алгоритмов

- **FCFS (First Come, First Served)** — процессы выполняются в порядке прибытия.
- **SJF (Shortest Job First)** — первым выбирается доступный процесс с наименьшим временем выполнения. Алгоритм невытесняющий.
- **RR (Round Robin)** — каждому процессу выделяется квант времени. Если процесс не завершился, он возвращается в конец очереди.

В данной работе для RR используется квант времени `q = 4`.

### 3. Реализация

Программа `scheduler.py`:
- считывает процессы из файлов `set1.txt`, `set2.txt` и `set3.txt`;
- пропускает строки-комментарии, начинающиеся с `#`;
- строит текстовую диаграмму Ганта;
- рассчитывает среднее время ожидания;
- рассчитывает среднее время turnaround.

### 4. Результаты

| Набор | Алгоритм | Среднее ожидание | Средний turnaround |
|---|---|---:|---:|
| set1 | FCFS | 8.75 | 15.25 |
| set1 | SJF | 7.75 | 14.25 |
| set1 | RR | 11.75 | 18.25 |
| set2 | FCFS | 146.30 | 165.05 |
| set2 | SJF | 132.80 | 151.55 |
| set2 | RR | 255.95 | 274.70 |

### 5. Анализ результатов

Для наборов set1 и set2 наименьшие средние значения времени ожидания и turnaround показал SJF.

Для set3 лучшие средние значения показал RR с квантом 4. В наборе есть длинный процесс P1 с временем выполнения 60, а большинство остальных процессов короткие. RR позволяет другим процессам получать процессорное время, пока длинный процесс не завершён.

### 6. Вывод

В ходе практической работы реализованы FCFS, SJF и Round Robin. Сравнение показало, что эффективность алгоритма зависит от времени прибытия процессов, длительности их выполнения и выбранного кванта времени.
