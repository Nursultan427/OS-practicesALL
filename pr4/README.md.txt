# Практическая работа №2
## Bash-скрипты и системные вызовы

### 1. Цель работы

Научиться работать с Bash-скриптами, обрабатывать текстовые файлы и изучить системные вызовы Linux с помощью утилиты `strace`.

### 2. Создание скрипта stats.sh

Был создан скрипт `stats.sh`, который обрабатывает все файлы `data/*.log`.

Скрипт выполняет следующие действия:
- Находит файлы с расширением `.log`.
- Подсчитывает количество строк, содержащих `ERROR`, с помощью `grep -c`.
- Суммирует количество ошибок с помощью `$(( ))`.
- Определяет файл с наибольшим количеством ошибок.
- Выводит результаты в терминал.

### 3. Результат работы скрипта

Выполненные команды:

```bash
chmod +x stats.sh
./stats.sh
```

Результат выполнения:

Вставить сюда реальный вывод команды `./stats.sh`.

### 4. Анализ системных вызовов

Для анализа использовались команды:

```bash
strace -c ls
strace -c cat data/01.log
```

Три наиболее частых системных вызова для каждой команды:

1. **[Название вызова №1]** — [краткое объяснение].
2. **[Название вызова №2]** — [краткое объяснение].
3. **[Название вызова №3]** — [краткое объяснение].

Результаты необходимо заполнить по столбцу `calls` в выводе `strace -c`.

### 5. Анализ вызова openat

Использовалась команда:

```bash
strace -e trace=openat cat data/01.log
```

`openat` — системный вызов Linux, который позволяет открыть файл относительно указанного каталога.

Программа `cat` сначала открывает необходимые динамические библиотеки и другие ресурсы, требуемые для запуска, а затем открывает файл `data/01.log` для чтения.
