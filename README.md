### 3. Создание структуры каталогов

Для создания каталогов использовалась команда:

```bash
mkdir -p ~/os-course/pr01
cd ~/os-course/pr01
```

Команда `mkdir -p` создаёт необходимые каталоги, а `cd` позволяет перейти в указанный каталог.

### 4. Создание и заполнение файла

Для создания файла и записи текста использовались команды:

```bash
echo "My first OS practice" > about.txt
echo "I am learning Linux commands" >> about.txt
cat about.txt
```

Результат выполнения команды `cat about.txt`:

```text
My first OS practice
I am learning Linux commands
```

Оператор `>` записывает текст в файл, заменяя прежнее содержимое. Оператор `>>` добавляет текст в конец файла. Команда `cat` выводит содержимое файла в терминал.

### 5. Просмотр файлов и прав доступа

Для просмотра файлов использовалась команда:

```bash
ls -la
```

Объяснение столбцов вывода для файла `about.txt`:

1. **Права доступа** — тип файла и разрешения на чтение, запись и выполнение.
2. **Количество ссылок** — число жёстких ссылок на файл.
3. **Владелец** — пользователь, которому принадлежит файл.
4. **Группа** — группа, к которой относится файл.
5. **Размер** — размер файла в байтах.
6. **Дата и время** — время последнего изменения файла.
7. **Имя файла** — название файла.

Ключ `-l` показывает подробную информацию, а `-a` отображает в том числе скрытые файлы и каталоги.

### 6. Установка необходимых программ

Для обновления списка пакетов и установки программ использовались команды:

```bash
sudo apt update
sudo apt install -y git python3 build-essential
```

Назначение установленных инструментов:

- **Git** — система контроля версий для отслеживания изменений в проектах.
- **Python 3** — интерпретатор языка программирования Python.
- **build-essential** — набор инструментов для компиляции программ.

### 7. Работа с Git

Для загрузки проекта из GitHub Classroom использовалась команда:

```bash

```

Для сохранения изменений и отправки их на GitHub:

