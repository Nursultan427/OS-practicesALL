# Практическая работа №2
## Bash-скрипты и системные вызовы

### 1. Цель работы

Изучить Bash-скрипты, обработку лог-файлов и системные вызовы Linux.

### 2. Скрипт stats.sh

Скрипт обрабатывает файлы `data/*.log`, считает количество строк с `ERROR`, вычисляет общую сумму ошибок и определяет файл с наибольшим количеством ошибок.

Для подсчёта используется `grep -c`, для суммирования — `$(( ))`.

### 3. Результат работы

```text
data/01.log: 2 ошибок
data/02.log: 1 ошибок
data/03.log: 0 ошибок
Всего ошибок: 3
Больше всего ошибок: data/01.log (2)
```

### 4. Анализ системных вызовов

Выполнены команды:

```bash
strace -c ls
strace -c cat data/01.log
```

Три наиболее частых системных вызова и их назначение необходимо указать по результатам `strace -c`.

### 5. Анализ openat

Выполнена команда:

```bash
strace -e trace=openat cat data/01.log
```

`openat` используется для открытия файлов. При запуске `cat` система открывает необходимые динамические библиотеки и другие ресурсы, после чего программа открывает лог-файл для чтения.

### 6. Вывод

В ходе работы изучены циклы Bash, подсчёт ошибок в лог-файлах, арифметические операции и анализ системных вызовов с помощью `strace`.
